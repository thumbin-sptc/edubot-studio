# 콘텐츠 변경·배포 정책 (2026-11-12)

## 핵심 상태
- `draft`: 예시·검토 중. 서비스 공개 불가.
- `reviewed`: 원문, 변수, 출처, 권리 확인 단계. 서비스 공개 불가.
- `published`: 교재 원문 및 배포 권한, 서비스 삽입 위치를 검수한 승인본. 서비스 공개 가능.

현재 `SC-001`, `SS-001` 두 템플릿은 `draft`이며, `content/prompt-inventory.json` 43개 항목(공식 34개·추가 후보 9개)은 **전체 확정 교재가 아닌 메타데이터 목록**이다.

## 원문 버전과 생성본
- 사용자 제공 원고의 특정 시점 문구를 `sourceOriginalText`로 보존.
- 입력 변수 삽입 위치만 `templateText`에서 변경. 그 외 문장 자동 재작성 금지.
- `version`은 프롬프트별로 독립적인 SemVer 문자열로 기록하고, `id`는 동일 유지.
- 수정된 프롬프트의 저장된 옛 작성 초안은 **구 버전 그대로 남기거나 명시적으로 전환**. 신규 템플릿으로 침묵 속 재생성 금지.
- 공개 템플릿을 새 버전으로 교체하기 전에 원문·placeholder·단계·샘플 출력 회귀 검수.

## 자료 파일/영상
- 권리·라이선스가 명확한 지식 파일만 다운로드 가능하게 공개.
- 플랫폼별 튜토리얼은 시연 영상/GIF 및 텍스트 대안이 준비되고, 실제 PC/모바일 웹 지원 여부를 확인한 후 공개.
- 영상·지식 파일이 없으면 '준비 중' 상태로 표시하고 기능이 존재한다고 속이지 않음.

## 학생 정보
- 예제는 가명·가공된 사례만 사용. 실제 식별 가능 학생 데이터, 건강/복용약 등 민감정보 저장소 반입 금지.
- 서버 저장/전송·AI API 없음. 사용자 스스로 외부 AI에 붙여넣을 때 해당 서비스의 정책 적용.

## 향후 IEP
- 프롬프트 카테고리 및 스키마는 확장 가능하게 두되 원고 미확정 상태에서는 IEP 자동 작성법이나 평가기준을 지어내 게시하지 않음.
