# UX 상세 명세

## 공통

- **마법사:** 상단 제목, 단계 번호/진행 바, 선택 가능한 완료 단계, 본문, 하단 이전·다음. 돌아갔을 때 입력값 유지.
- **PC 메뉴:** 상단 가로 내비게이션. **모바일 메뉴:** 하단 고정 메뉴(홈/에듀봇/프롬프트). Wizard 내부에서 일반 메뉴를 숨기고 단계 버튼으로 대체.
- **브랜드:** 토스형 친근하고 직관적인 UI, 화이트 기반·연구회 네이비/스카이블루 및 소량의 연두. 에듀봇 캐릭터는 작은 단계별 도우미. 장식용 모션 최소화.
- **접근성:** 키보드/포커스 표시, 폼 레이블, 스크린리더 안내, 동작 줄이기, 영상의 일시정지 및 텍스트 대안.

## 1. 홈

동등한 '나만의 에듀봇 만들기'와 '프롬프트 라이브러리' 카드. 로그인 없음. 처음 방문한 사용자는 어느 기능이든 바로 들어간다.

## 2. 제작 경로

1) `platform` = chatgpt / claude / gemini 선택.
2) `device` = desktop-web / mobile-web 선택.
3) 선택 조합에 따라 단계 목록 호출. 플랫폼 변경 시 개인화 설정 값은 유지.
4) 단계별 PC는 **좌측 시연 + 우측 설명/리소스**, 모바일은 **영상 → 설명 → 리소스**.
5) 단계별 `action`에 따라 지침 복사/링크 열기/파일 다운로드/사용자 체크 표시.
6) 외부 AI의 실행 상태를 자동 확인하지 않는다. '지침 복사됨'은 'AI에 등록됨'과 다름.
7) 필요한 경우 지침 개인화(학교급/교육환경/익명 학급 구성/교육 방향/추가 요청). 기본 지침 본문은 변경 금지.
8) 파일 목록: 공통 기본 선택, 추천 초기 체크, 자유롭게 수정. 개별·선택 묶음 다운로드. 공개 권한 없는 파일 미노출.
9) 테스트: 역할/지식/선택형 개인화, 복사·확인 기준·문제 발생 단계 이동. AI 답변으로 완전한 설정 성공 보장 불가.

## 3. 라이브러리

- 검색 및 활용 목적별(기본)/교재 목차별 두 탭.
- 각 카드에 설명, 카테고리, 교재 위치, [시작/이어서], 저장 내용 삭제.
- 데이터 원본은 하나이며 분류는 메타데이터 기반.

## 4. 프롬프트 입력 경로

1) 선택한 템플릿의 `steps` 로드.
2) 한 단계는 단일 주제와 관련 문항 2~4개를 원칙으로 함.
3) `single-select`, `multi-select`, `short-text`, `long-text`, `number`, `repeatable` + 기타 입력 지원.
4) 필수값 미입력 시 정확한 위치와 이유 표시. 항목 예시/도움말은 원문에 임의로 삽입하지 않음.
5) 참고자료별 `external-file` 또는 `text-input` 선택; 웹앱의 파일 직접 업로드 기능은 만들지 않음.
6) 모든 입력 완료 후 원문+변수 치환으로 자동 생성본 렌더링.
7) 최종 텍스트를 사용자 사본으로 편집 가능. 되돌리기 시 생성본으로 복원.
8) 입력 단계로 돌아와 값 변경 시 기존 자유 편집본과 충돌하면 확인 메시지 후 재생성.
9) 복사 버튼은 현재 표시된 최종 사본을 대상으로 하며 실패 시 직접 선택·복사 안내.
10) 완성 화면에서 외부 AI 출력 붙여넣기, 후속 템플릿 추천, 후속 템플릿 지정 필드에 이전 AI 출력 불러오기.

## 5. 로컬 데이터

- 기본: 영속 저장 OFF, 현재 앱 메모리에서 단계 전환 중 내용 유지.
- 사용자가 저장을 ON하면 프롬프트별 draft, 단계, 최종 수정 사본, 붙여넣은 AI 답변 및 제작 개인화/진행 상태를 로컬 브라우저에 저장.
- ON/OFF는 기존 저장 내용 삭제와 다르다.
- 개별 삭제와 전체 삭제 지원. 삭제 전 확인.
- 영구 보장을 약속하지 않으며, 브라우저 정리·기기 변경 시 유실 가능성을 안내.
- 로컬 저장은 암호화 개인 보관소가 아니므로 공용 기기 저장 주의.

## 6. 개인정보 고지와 실패 복구

- 첫 프롬프트 진입 시 익명화·외부 서비스 처리 안내, 학생 관련 입력칸에 간단한 고지, 완성본 복사 근처 주의.
- 복사 오류 → 본문 선택 허용 / 다운로드·ZIP 오류 → 개별 파일 / 시연 오류 → 텍스트+정지 이미지 / 저장 오류 → 메모리 내 입력 유지 및 사용자 안내 / 외부 접속 오류 → 공식 링크 / 필수값 누락 → 항목 강조.

## 7. 미정(UI 콘텐츠)

실제 색상 HEX, 캐릭터 파일, 플랫폼별 시연 GIF/영상, 교재 프롬프트 원문/페이지 및 사용자 질문 문항은 공급 후 확정. 그전에는 임의의 확정 콘텐츠를 만들지 않는다.
