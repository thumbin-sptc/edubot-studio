# 첫 콘텐츠 검수 기록

대상은 특수학급 「교사철학 작성하기」(`SC-001`, `0.1.0`)입니다. 저장소에서 `draft`이며 `lastReviewedAt`은 비어 있습니다. 공개 프롬프트와 제작 가이드는 각각 0건입니다.

## 기존 JSON과 코드에서 확인한 사항

| 항목 | 확인 결과 |
| --- | --- |
| 출처 | `source.document`는 특수학급, `source.pdfPage`는 기존 PDF의 7쪽, 유형은 작성 프롬프트입니다. JSON은 2026-11-12 PDF 발췌의 1차 대조를 기록합니다. |
| 분류·목차 | 교육과정 설계 / 특수학급. 인벤토리의 학교급은 공통, 섹션은 ‘교육철학 및 교육 방향 설계’입니다. JSON의 교재명·목차 표기는 잠정이며 최종 교재 제목·장·절·인쇄 쪽수는 미확인입니다. |
| 원문·고정 지시문 | 저장소의 예시 다섯 항목을 불릿 목록으로 만들어 `{{educationalBeliefs}}`에 되돌려 넣으면 `sourceOriginalText`와 줄바꿈까지 일치합니다. 시범 전사의 역할, 요청, 고정 문구와 문단 구분은 치환 대상 밖에 있습니다. |
| 편집 주석 | 출처 메모는 교육관 제목 옆 입력 지시 표시를 편집 주석으로 분류합니다. 저장소 시범 전사와 템플릿은 해당 표시와 결과 예시·TIP을 복사 본문에 포함하지 않습니다. |
| 입력·단계 | ‘교육관 입력’과 ‘프롬프트 완성’ 두 단계입니다. `educationalBeliefs`는 장문 반복 필드 1개이며 한 항목 이상 필요합니다. 최대 항목 수는 설정되어 있지 않습니다. 기본 배열은 비어 있고, 예시는 펼쳐 보는 참고용입니다. |
| 후속 연결 | `SC-002`는 인벤토리의 후속 후보입니다. 공개 템플릿이 없어 추천 링크와 상세 페이지가 생성되지 않습니다. |
| 개인정보·저장 | 작성 시작 화면에 익명화 안내, 복사 화면에 외부 AI와 개인정보 안내가 있습니다. 해당 교육관 필드에는 필드별 민감정보 표시가 설정되어 있지 않습니다. 자동 저장 기본값은 OFF이며 켠 경우에만 브라우저에 저장합니다. 이전 버전 작성본은 내 데이터 관리에서 확인할 수 있습니다. |

## 승인 대기

| 항목 | 상태 |
| --- | --- |
| 최신 교재 판본, 원문 전사, 고정 지시문, 편집 주석의 성격, 치환 구간과 교육학적 적합성의 대조 | 미확인 |
| 제목·설명·교재명·장절·PDF 및 최종 인쇄 쪽수 | 최종 정보 미확인 |
| 검수자와 검수일, 공개 권한의 근거, 운영자의 명시적 게시 결정 | 승인 대기 |
| ChatGPT PC 웹 가이드의 지침, 지식 파일, 시연·설명과 조합별 승인 | 별도 승인 대기 |

기존 JSON 내부의 일치는 저장소 시범 전사에 대한 검수 결과입니다. 최종 자료와 승인 기록은 [등록에 필요한 자료](FIRST-CONTENT-INPUTS.md)에서 확인할 수 있습니다.

## 재검사

운영 저장소에서 아래 명령을 실행합니다. 작성·복사·저장·버전 보존 흐름은 원격이 없는 격리 복제본에서 합성 입력과 테스트 전용 승인 값으로 확인합니다. 운영 배포 이후에는 상세와 원본 JSON의 404 및 공개 건수를 확인합니다. 실제 등록 절차는 [콘텐츠 공개 체크리스트](CONTENT-RELEASE.md)를 따릅니다.

```bash
npm run validate:content
npm test
npm run lint
npm run typecheck
npm run build
node scripts/check-public-build.mjs
```
