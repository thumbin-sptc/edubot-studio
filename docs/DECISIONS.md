# EDU-BOT Studio | 확정 결정 및 전체 기획

- **문서 상태:** 기획 1차 확정안 / 콘텐츠 입력 전
- **버전:** 0.1
- **기준일:** 2026-11-12
- **기획·운영:** 중도중복장애교육연구회
- **개발 예정:** Codex · GitHub · Vercel

> **서비스 한 문장:** 연구회의 지침과 지식 자료로 교사가 자신의 에듀봇을 만들고, 교재의 프롬프트를 질문에 답하는 방식으로 완성하는 무료 웹앱.

## 1. 서비스 목표와 사용자

**핵심 사용자**는 특수학교·특수학급 교사이며, 생성형 AI 활용 경험이 적어도 설명 없이 따라갈 수 있어야 한다. 서비스는 두 기능을 **동등한 비중**으로 제공한다.

1. **나만의 에듀봇 만들기:** ChatGPT 프로젝트, Claude 프로젝트, Gemini Gem을 플랫폼별·기기별 단계에 따라 만들어 간다. 각 단계에 시연 GIF/짧은 반복 영상, 설명, 필요한 지침 복사·자료 다운로드를 함께 제공한다.
2. **프롬프트 라이브러리:** 교재 프롬프트를 활용 목적·교재 목차로 찾아, 프롬프트별 맞춤 마법사에 정보를 단계적으로 입력하고, 결과를 복사·편집한다. AI가 생성한 결과를 사용자가 직접 붙여넣어 다음 프롬프트에 활용할 수 있다.

**초기 버전에서 하지 않는 것:** AI API 호출, 에듀봇 자동 생성·원격 설정, 외부 AI 대화 자동 읽기, 회원가입, 사용자 데이터 서버 저장, 데이터베이스, 별도 관리자 페이지, 로컬 데이터 백업 파일 입출력.

## 3. 정보 구조(IA)와 주요 화면

```text
홈 /
├─ 나만의 에듀봇 만들기 /create
│  ├─ AI 플랫폼 선택 + 기기 선택
│  ├─ 플랫폼/기기 맞춤 단계별 튜토리얼
│  │  ├─ 프로젝트·Gem 생성
│  │  ├─ 연구회 지침 + 선택형 개인화 + 복사
│  │  ├─ 공통/추천/선택 지식 파일 확인·다운로드
│  │  └─ 완료 체크 (실제 순서는 플랫폼별로 다를 수 있음)
│  └─ 에듀봇 테스트 / 완료
├─ 프롬프트 라이브러리 /prompts
│  ├─ 활용 목적별 / 교재 목차별 탐색
│  └─ 프롬프트별 단계형 작성 /prompts/[id]
│     ├─ 맞춤 질문 단계
│     ├─ 참고 자료 제공 방법 선택
│     └─ 완성본 편집·복사 / AI 결과 붙여넣기 / 후속 추천
├─ 내 데이터 관리 /data
└─ 이용 안내·연구회 소개 /help
```

### 3.1 홈
- 대표 문구 아래 동일한 시각적 비중의 두 기능 카드.
- 기능마다 한 문장 설명과 명확한 CTA 제공.
- PC 가로 2열, 모바일 세로 1열.
- 하단에 연구회 소개, 이용 안내, 개인정보 유의사항.

### 3.2 에듀봇 시작 화면
- AI 서비스 선택: ChatGPT / Claude / Gemini.
- 제작 환경 선택: PC 웹 / 모바일 웹.
- 선택 결과에 맞는 튜토리얼 데이터를 불러옴.
- 모바일 웹에서 실제로 불가능한 기능은 해당 단계에서 PC 사용 경로 제시.
- 플랫폼이나 기기를 바꿔도 현재 입력한 개인화 정보는 유지.

### 3.3 에듀봇 단계별 화면
- 화면 상단: 현재 단계 번호·제목·진행률·완료 체크 상태.
- PC: 왼쪽 실제 조작 시연, 오른쪽 1~3문장 안내 + 그 단계의 복사/다운로드 버튼·체크.
- 모바일: 시연 → 안내 → 조작 → 이전/다음.
- 복사 동작 성공과 외부 AI에 **등록 완료**는 별개의 상태.
- 체크하지 않아도 이전/다음 자유 이동.
- 단계 구성은 플랫폼×기기별 데이터 정의. GIF와 별도로 텍스트 대안 필수.

### 3.4 에듀봇 지침 개인화
- 기본 지침은 원문 불변.
- 선택: 기본만 사용 / 개인화 추가.
- 개인화 필드 예시: 학교급, 특수학급·특수학교, 학급 구성(익명), 교육 방향, 추가 요청.
- 최종 복사물 = 기본 지침 + (선택한 경우 개인화 섹션).
- 지침의 글자 수 또는 기능 제한이 플랫폼별로 다르면 안내. 자동 설정은 하지 않음.

### 3.5 지식 파일 선택
- 공통 자료 기본 선택, 선택 자료는 학교급/환경 기반 추천.
- 추천 체크는 사용자가 자유롭게 변경 가능.
- 파일 카드에 제목·간략 설명·용량·활용 목적·필요시 출처·다운로드 버튼.
- 개별 다운로드와 선택 파일 묶음(ZIP) 다운로드 제공, ZIP 압축 해제 안내.
- 업로드 제한 및 저작권 검토가 끝나지 않은 파일은 공개 배포하지 않음.
- 다운로드 실행 여부만 웹앱에서 알 수 있고 AI에 실제 업로드되었는지는 직접 체크.

### 3.6 테스트·완료 화면
- 역할 확인, 지식 파일 활용 확인, 개인화 반영 확인(개인화 시에만)의 테스트 질문 복사.
- 테스트마다 '확인할 점' 및 문제 시 관련 단계로 돌아가기 제공.
- 실제 AI 응답을 웹앱이 자동 검증하거나 가져오지 않음.
- 마지막에 프롬프트 라이브러리로 이어지는 CTA 제공.

### 3.7 프롬프트 라이브러리
- 검색창, [활용 목적별]/[교재 목차별] 탭, 필터.
- 카드: 제목, 요약, 카테고리, 교재 장·절·페이지(확인 후), [사용하기], 저장된 작성 내용이 있으면 [이어서].
- 원본 데이터 하나에 탐색용 메타데이터만 다르게 적용. 중복 프롬프트 생성 금지.

### 3.8 프롬프트 작성 마법사
- 템플릿별 단계 수·주제·문항 개별 정의, 공통 Wizard 화면 사용.
- 단계당 동일 주제의 2~4개 관련 문항을 원칙으로 하되 복잡한 경우 예외 허용.
- 지원 입력: 단일/복수 선택, 짧은/긴 글, 숫자, 반복 카드, 기타 입력, 예시 펼치기.
- 필수 정보가 없으면 다음 단계에서 그 항목에 구체적인 오류 안내.
- 관련 입력값은 단계 전환 시 메모리에 유지. 장기 브라우저 저장은 사용자 동의 시에만.
- 개인정보 관련 문항에는 '학생 A' 등 익명화 안내.

### 3.9 참고 자료 단계
- 참고 자료별 제공 방법: 'AI에 파일로 첨부' / '직접 내용 입력'.
- 파일 선택 시 AI 서비스에 직접 파일을 올리도록 체크리스트 제공.
- 텍스트 선택 시 해당 템플릿의 지정된 placeholder/선언된 참고 자료 영역에만 값 삽입.
- 웹앱 자체는 교사의 수업 자료 파일을 받거나 업로드하지 않음.
- 원문에 지정되지 않은 곳에 임의로 지침을 쓰거나 문단을 생성하지 않음.

### 3.10 프롬프트 완성·편집
- 모든 필수 값 충족 시 원문을 기반으로 **자동 생성본** 작성.
- 사용자가 생성본 사본을 직접 편집할 수 있음. 원본 템플릿은 불변.
- [복사]는 현재 편집된 최종 결과를 복사함.
- [입력 내용 수정]으로 특정 단계에 돌아갈 수 있음.
- 입력값 변경 후 이미 편집한 최종 텍스트가 있으면 덮어쓰기 전에 확인.
- [자동 생성본으로 되돌리기]는 사본 편집만 취소하며 사전 확인 제공.
- 복사 직전 외부 AI 전송과 개인정보 관련 짧은 주의 안내.

### 3.11 이전 AI 결과 활용
- 외부 AI가 생성한 답변을 사용자가 웹앱에 붙여넣고 '이전 결과'로 등록.
- 다음에 추천된 프롬프트로 이동 시, 그 결과를 템플릿에 선언된 참고 자료·입력란으로 채우는 선택지 제공.
- 후속 추천은 선택 사항이며 모든 프롬프트는 독립 접근 가능.
- 로컬 저장 OFF: 현재 사용 중인 앱 세션에서만 유지하며 새로고침·창 종료 시 사라질 수 있음.

### 3.12 내 데이터 관리·도움말
- 프롬프트별 로컬 데이터 삭제, 전체 데이터 삭제, 현재 저장 ON/OFF 확인.
- 저장 OFF로 전환해도 기존에 저장된 정보는 자동 삭제되지 않음. 삭제는 별도 동작.
- 삭제 전 확인 및 복구 불가 안내.
- 외부 AI에 직접 첨부하는 방법, 플랫폼별 최신 안내 확인일, 오류 해결 안내 제공.

## 4. 로컬 저장과 개인정보 보호

- **기본:** 작성 내용 자동 저장 꺼짐. 단계 간 데이터는 메모리 유지.
- **선택적 활성화:** 브라우저 `localStorage`에 프롬프트별 단계·입력값·편집본·사용자가 붙여넣은 AI 결과 및 에듀봇 개인화/진행 상태 저장.
- **만료:** 앱이 별도의 자동 만료 시간을 두지 않음. 브라우저 정리·시크릿 모드·기기 교체 등으로 데이터가 소실될 수 있음.
- **프라이버시:** `localStorage`는 해당 브라우저 프로필에서 접근 가능하고 암호화 보관소가 아님. 공용 기기에서 저장 비권장.
- **네트워크:** 사용자 입력 텍스트를 웹앱 서버로 전송하는 API를 만들지 않음. 외부 AI로 복사·붙여넣은 뒤의 처리 조건은 각 서비스가 정함.
- **안내:** 첫 프롬프트 진입 때 주의 고지, 학생 관련 필드 인라인 고지, 복사 단계의 전송 경고.
- **삭제:** 개별 삭제와 전체 삭제. 브라우저 내 데이터가 남지 않았는지 구현 테스트.

## 5. 오류 대응·접근성

- 복사 실패 → 본문 텍스트 선택·복사 안내.
- ZIP 실패 → 개별 파일 다운로드.
- GIF/영상 오류 → 텍스트 단계 안내와 정지 이미지(확보 시).
- 저장 실패(용량 등) → 내용 유지한 채 오류 고지, 자동 저장 활성 상태 재확인.
- 외부 AI 접속 문제 → 해당 서비스의 공식 진입 링크.
- 필수 항목 오류 → 해당 필드로 포커스·이유 안내.
- 키보드 탐색, 라벨/오류 메시지 연결, 충분한 버튼 크기, 색상 대비, 동작 줄이기, 영상 일시정지/대체 텍스트를 지원.

## 6. 개발·콘텐츠 운영

- **확정:** Codex로 개발하고 GitHub 저장소에서 코드 및 콘텐츠 파일 관리. `main` 변경 시 Vercel 프로덕션 자동 배포.

## 7. 아직 실제 자료를 받아야 확정할 내용

이 항목은 **29개 기획 결정과 모순되지 않는 미완성 콘텐츠 작업**이다.

1. **교재 프롬프트 전체 원문:** 실제 프롬프트 목록, 장·절/페이지, 입력 placeholder 및 선택 삭제 구간, 사전 정의 가능한 첨부/직접 입력 위치.
2. **기존 GPTs 프로젝트 기본 지침:** 원문, 서비스별 글자/기능 제한 확인 후 필요 시 분리 제공 전략 검토.
3. **지식 파일 목록 및 저작권:** 공통/선택 분류, 추천 매핑, 용량, 플랫폼 업로드 제한, 공개 배포 권한.
4. **플랫폼별 실습 절차:** ChatGPT·Claude·Gemini의 현재 PC·모바일 웹 실제 지원 범위, 링크, 시연 영상과 텍스트 대안.
5. **브랜드 자산:** 에듀봇 캐릭터 원본, 연구회 로고, 색상 코드, 폰트 등.
6. **프롬프트 연결 관계:** 어느 출력물을 어떤 후속 입력으로 연결하는지 실제 교재 기준 매핑.

## 8. 개발 전 일관성 검토: 해결 원칙

| 발견한 긴장 관계 | 모순 없는 처리 원칙 |
| --- | --- |
| 원문 보존 vs 최종 프롬프트 직접 편집 | **원문 템플릿은 변경 불가**, 결과 사본만 편집. |
| 원문 보존 vs 선택 영역 삭제·직접 입력 | 사전 선언된 placeholder·선택 블록에서만 치환·삭제, 기타 문장 불변. |
| 프롬프트 단계별 수정 vs 수동 편집본 유지 | 입력값 변경 시 수동 편집본 덮어쓰기 전에 확인; 무통보 초기화 금지. |
| 로컬 자동저장 OFF vs 이전 결과 연결 | 페이지 내 앱 메모리로 전달; 새로고침 이후 복원은 약속하지 않음. |
| 로컬 보관 무기한 vs 실제 영구 저장 | 앱은 만료 시간을 두지 않되 브라우저가 데이터를 지울 수 있음을 고지. |
| GIF 안내 vs 모바일 웹 미지원 | 실제 미지원 기능을 시연하는 대신 PC 경로 안내. 기능 확인 전 '지원' 확언 금지. |
| 지식 파일을 추천 vs 일부 파일 배포 불가 | 권리 확인된 공개 자료만 추천·다운로드 목록에 노출. |
| 바로 배포 vs 안정성 | PR 필수 아님. 타입/빌드/스키마 검사 권장, 이전 커밋으로 복구 가능. |
| '서버 전송 없음' vs 외부 AI 활용 | 웹앱은 미전송; 사용자가 외부 AI에 붙여넣는 순간 별도의 데이터 처리 발생. |
