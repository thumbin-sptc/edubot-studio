# PRD — EDU-BOT Studio

**상태:** 2026-11-12 기획 1차 확정 / 실제 콘텐츠 입력 전

## 제품 정의

특수교육 교사가 연구회에서 공개 가능한 지침·지식 파일을 내려받고, 플랫폼별 단계형 안내를 따라 자신의 ChatGPT/Claude 프로젝트 또는 Gemini Gem을 직접 만든다. 교재 프롬프트는 목적 또는 목차로 찾아 질문형 Wizard를 통해 완성·편집·복사한다.

## 사용자 가치

- AI 도구에 익숙하지 않아도 시연을 보고 단계별로 따라 만든다.
- 교재의 복잡한 프롬프트를 대괄호 직접 수정 없이 입력형으로 활용한다.
- 이전 AI 생성 결과를 직접 복사해서 후속 설계 프롬프트에 재사용할 수 있다.
- 데이터 저장은 사용자가 통제하며 로그인 없이 사용한다.

## 필수 범위(MVP)

1. **홈:** 동등한 2개 주요 CTA, 연구회 안내.
2. **제작 마법사:** AI 플랫폼·PC/모바일 웹 선택, 해당 기기별 단계형 GIF/반복 영상, 설명, 지침 복사, 개인화, 공통/추천/선택 파일 다운로드, 체크, 역할·지식·개인화 테스트.
3. **라이브러리:** 목적별/목차별 탐색 탭, 검색, 필터, 수록 위치 표시.
4. **프롬프트 작성:** 템플릿별 단계/문항, 여러 필드 유형, 필수값 검사, 예시, 참고 자료 파일 첨부 안내 또는 직접 텍스트 입력, 최종 생성본 직접 수정, 복사, 자동 생성본 복원.
5. **연결:** AI 출력 사용자가 붙여넣기, 후속 템플릿 추천, 지정 입력 위치에 불러오기.
6. **저장·삭제:** opt-in `localStorage`, 삭제 및 저장 ON/OFF 구분, 저장 내용 개별/전체 삭제.
7. **사용성:** 반응형·접근성, 최소 모션, 단계 진행 표시, 복사/다운로드/영상/저장 실패의 대체 경로, 개인정보 주의.
8. **운영:** JSON/TypeScript 콘텐츠 파일, GitHub main → Vercel 자동 배포.

## 범위 밖

- 백엔드 데이터베이스·로그인·계정 동기화·AI API.
- 파일 업로드 후 웹앱 내부에서 분석 또는 외부 AI로 자동 전송.
- 외부 AI 대화 읽기/결과 자동 가져오기.
- 모바일 네이티브 앱 튜토리얼, 사용자 백업 JSON 입출력.
- 관리자 CMS, 자동 프롬프트 원문 재작성.

## 정보 구조

- `/` 홈
- `/create` AI·기기 선택
- `/create/[platform]` 단계형 제작(기기별 내용 전환)
- `/prompts` 라이브러리
- `/prompts/[id]` 프롬프트 작성
- `/data` 로컬 데이터 관리
- `/help` 이용 안내 및 연구회 소개

라우트는 구현상 수정 가능하며 외부 연결의 사용자 목표는 유지한다.

## 2026-11-12 추가 확정 사항 (v0.3)

- Notion 미사용. 혼자 개발/관리하므로 GitHub가 코드와 문서의 유일한 기준 저장소이다.
- 교재 프롬프트 문구는 변경 가능하다. 정식 교재 확정 전 전체 34개를 공개용으로 고정하지 않는다.
- `id`는 유지하며 템플릿 `version`·`status`·수정 시각·출처를 추적한다. 기존 로컬 작성본은 버전 불일치 시 무통보 덮어쓰지 않는다.
- 향후 IEP 작성 지원 프롬프트를 추가할 수 있게 카테고리/입력 단계 구조를 일반화하되, 임의의 IEP 본문을 생성하여 공개하지 않는다.
- 구현 우선순위는 공통 UI/Wizard 엔진 검증 → 플랫폼별 제작 기능 → 확정된 교재 원고 투입이다.
