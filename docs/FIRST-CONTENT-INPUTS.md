# 첫 콘텐츠 등록에 필요한 자료

## SC-001 교사철학 작성하기

- [ ] 최신 또는 확정 원문 텍스트/PDF, 판본 식별자, 정확한 출처.
- [ ] 그대로 유지할 지시문과 문장, 편집 주석으로 제외할 표시, 교육관 입력으로 바꿀 구간. 참고 예시와 생성 결과도 함께 확인합니다.
- [ ] 화면 제목·요약, 교재명·장·절, PDF 쪽수와 확인된 최종 인쇄 쪽수.
- [ ] 연구회 검수자와 검수일, 공개 권한을 확인한 근거, 해당 버전에 대한 운영자의 명시적 게시 승인.

## ChatGPT PC 웹 제작 가이드

- [ ] 연구회 기본 지침의 승인 원문과 버전, 배포 권한.
- [ ] 공통 지식 파일 1개 이상과 선택 파일(있는 경우), 각 파일의 저작권·배포 라이선스.
- [ ] 실제 ChatGPT PC 웹에서 검증한 조작 순서·단계별 설명·확인일, 검증한 공식 진입 링크.
- [ ] 단계별 GIF 또는 영상, 텍스트 대안, 필요한 정지 이미지·자막, 시연 자료 사용 권한.
- [ ] 역할·지식·개인화 점검 질문과 확인 기준의 승인 문구. 개인화 점검은 개인화 사용 시 표시합니다.
- [ ] ChatGPT PC 웹 조합을 공개한다는 별도 승인.
