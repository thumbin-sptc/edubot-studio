# 기능별 검수 기준 — EDU-BOT Studio

체크리스트는 실제 콘텐츠 입수 전 공통 시스템의 검수 기준이다.

## 홈·메뉴
- [ ] PC 홈에 두 주요 기능이 동등하게 보인다.
- [ ] 모바일은 하단 메뉴가 보이고 Wizard 진입 시 집중형 버튼으로 전환한다.
- [ ] 프롬프트 라이브러리는 에듀봇 제작을 완료하지 않아도 진입 가능하다.

## 에듀봇 만들기
- [ ] ChatGPT/Claude/Gemini × PC/모바일 웹 조합에 따라 각기 정의된 튜토리얼이 표시된다.
- [ ] 단계에 실제 시연 영상, 텍스트 설명, 그 단계에 필요한 행동 버튼이 표시된다.
- [ ] 플랫폼 변경 시 개인화 입력값이 유지된다.
- [ ] 기본 지침 원문이 개인화하지 않은 상태에서 변형되지 않는다.
- [ ] 개인화하면 지침 하단에 분리된 섹션만 추가된다.
- [ ] 학교급/환경을 기반으로 선택 자료 추천이 나타나고 사용자가 수정할 수 있다.
- [ ] 파일은 개별/선택 묶음 다운로드가 가능하고 ZIP 오류에 개별 링크가 남는다.
- [ ] 복사/다운로드와 실제 AI 등록·업로드 완료 체크가 분리되어 있다.
- [ ] 체크하지 않고도 이전/다음 이동이 가능하다.
- [ ] 테스트 질문 3종을 제공하며 개인화하지 않은 경우 개인화 점검은 생략한다.

## 프롬프트 라이브러리
- [ ] 목적별/목차별 탐색 모두 동일한 프롬프트 엔터티를 참조한다.
- [ ] 검색·필터·교재 위치가 정상 작동한다.
- [ ] 템플릿마다 단계와 문항 수가 달라질 수 있다.
- [ ] 필수값을 비우면 필드 단위로 구체적 오류가 표시된다.
- [ ] '기타' 자유 입력, 학생별 반복 필드, 예시 안내가 작동한다.
- [ ] 참고 자료를 외부 AI 파일 첨부 또는 직접 텍스트 입력으로 선택할 수 있다.
- [ ] 원문의 지정된 placeholder/선택 블록 외의 문구가 변형되지 않는다.
- [ ] 완성본은 직접 편집 가능하며 원본 템플릿은 변경되지 않는다.
- [ ] 입력값 변경으로 수동 편집본이 덮어써질 때 경고가 표시된다.
- [ ] 복사는 현재 최종 편집본을 대상으로 하고 실패 시 수동 복사가 가능하다.
- [ ] 사용자가 붙여넣은 AI 결과를 후속 프롬프트의 지정 입력란에 선택적으로 불러올 수 있다.

## 개인정보·저장
- [ ] 저장 기본값 OFF이며 사용자 입력 텍스트를 서버에 전송하지 않는다.
- [ ] 저장 OFF인 경우 단계 전환은 유지되지만 새로고침 후 복원은 보장하지 않는다.
- [ ] 저장 ON인 경우 같은 브라우저에서 다시 접속해 이어쓰기 가능하다.
- [ ] 저장 OFF 전환만으로 기존 저장 정보가 삭제되지는 않는다.
- [ ] 개별 삭제/전체 삭제 후 해당 데이터가 실제 로컬 저장소에서 사라진다.
- [ ] 개인정보 안내가 최초/민감 입력란/복사 전 알맞게 노출된다.
- [ ] 저장 용량 오류 시 현재 입력값이 화면에서 사라지지 않는다.

## 접근성·오류 대안·배포
- [ ] 키보드만으로 주요 기능을 이용할 수 있다.
- [ ] 동작 줄이기 설정 시 불필요한 모션이 억제된다.
- [ ] 영상이 실패해도 텍스트 단계 설명을 확인할 수 있다.
- [ ] PC/모바일 화면에서 콘텐츠 겹침·잘림 없이 작동한다.
- [ ] TypeScript/빌드/콘텐츠 스키마 검사에서 실패하면 문제가 드러나도록 구성되어 있다.
- [ ] `main` 변경 시 Vercel 프로덕션 배포가 작동한다.
