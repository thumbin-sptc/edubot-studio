# 디자인 시스템 방향 (확정값과 미정값 구분)

## 확정된 스타일
- 토스에서 영감받은 깔끔한 UI: 화이트·네이비·스카이블루, 연두를 제한적으로 사용.
- 부드러운 모서리, 명확한 타이포그래피 위계, 정보 밀도 낮고 선명한 CTA.
- 데스크톱 상단 내비게이션 / 모바일 하단 내비게이션, 마법사 중에는 이전/다음으로 집중.
- 제작 마법사 PC 2열(좌 시연, 우 안내) / 프롬프트 마법사 PC 단일 가독성 중심 / 모바일 1열.
- 접근성: 키보드 포커스, 명확한 라벨과 오류 연결, 충분한 대비, `prefers-reduced-motion` 준수.

## 미정
- 색상 HEX, 브랜드 폰트, 본문 폰트, 공식 에듀봇 마스코트·로고 파일.
- 처음에는 `--color-...` 등 **교체 가능한 CSS 변수**로 표현하고 임시 수치임을 코드 주석에 명시한다.
- 가상의 에듀봇 마스코트를 최종 브랜드 자산으로 제작/포함하지 않는다.
