# EDU-BOT Studio

중도중복장애교육연구회가 특수교육 교사를 위해 만드는 무료 Next.js 웹앱입니다. 홈에서 에듀봇 제작과 프롬프트 라이브러리로 이동할 수 있습니다.

## 구현된 기능과 공개 상태

- **나만의 에듀봇 만들기**는 ChatGPT·Claude·Gemini의 PC 웹·모바일 웹 6개 조합을 지원하는 가이드 엔진입니다. 단계별 시연과 텍스트 대안, 기본 지침 복사와 개인화, 자료 추천, 개별·ZIP 다운로드, 외부 작업 자가 확인과 점검 질문을 제공합니다. ZIP은 한 번에 최대 20개·합계 24 MiB까지 지원하며, 실패하거나 한도를 넘으면 개별 파일을 내려받을 수 있습니다.
- **프롬프트 라이브러리**는 활용 목적·교재 목차별 탐색, 검색·필터, 단문·장문·숫자·단일 선택·복수 선택·반복 입력을 지원합니다. 완성본을 편집·복사하고, 외부 AI 답변을 직접 붙여넣어 보관하거나 허용된 후속 입력란으로 가져올 수 있습니다.
- **내 데이터 관리**에서는 프롬프트 작성본을 버전별로 열람·복사하고, 작성본과 제작 설정을 개별 또는 일괄 삭제할 수 있습니다. GitHub Actions는 푸시와 PR에서 콘텐츠·테스트·빌드·공개 경계를 검사합니다.

현재 **공개 프롬프트 0건, 공개 제작 가이드 0건**입니다. 교재 원고와 제작 지침·파일·시연 자료는 승인 및 권리 확인 후 등록합니다. 그전까지 라이브러리와 제작 안내에는 준비 중 상태가 표시됩니다. 인벤토리 43건과 시범 초안 2건은 검토 자료입니다.

## 로컬 실행과 검사

`package.json`의 Node.js 범위는 `^22.13.0 || ^24.0.0 || ^26.0.0`입니다. GitHub Actions와 같은 Node.js 24.x로 실행할 수 있습니다.

```bash
npm ci
npm run dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 열립니다. 운영 빌드와 공개 경계를 확인할 때는 아래 명령을 실행합니다.

```bash
npm ci
npm run validate:content
npm test
npm run lint
npm run typecheck
npm run build
node scripts/check-public-build.mjs
```

`npm run start`는 빌드 후 실행합니다. 테스트용 합성 템플릿과 가이드는 격리된 작업 공간에서만 활성화합니다.

## 브라우저 데이터와 원고 관리

자동 저장의 기본값은 **OFF**입니다. 사용자가 켜면 작성본·AI 답변·제작 설정을 해당 브라우저의 평문 `localStorage`에 보관합니다. 자동 저장을 꺼도 기존 저장 데이터는 남으며, 삭제는 내 데이터 관리에서 할 수 있습니다. 학생 식별 정보나 민감정보를 입력하지 마세요. 앱은 사용자 입력을 서버로 보내지 않습니다. 사용자가 외부 AI에 붙여넣거나 자료를 직접 첨부할 때는 해당 서비스의 처리 정책이 적용됩니다.

GitHub 저장소는 공개입니다. 앱에서 숨긴 초안도 GitHub의 파일과 이력에서 열람할 수 있으므로, 권리를 확인하지 않은 원고·파일은 비공개 작업 공간에서 검수합니다. 승인·등록·버전 관리 절차는 [콘텐츠 공개 체크리스트](docs/CONTENT-RELEASE.md)를 따릅니다.

## 배포

GitHub Pages는 저장소 문서를 게시합니다. Next.js 운영 앱은 Vercel 연결 후 별도로 배포합니다. 연결, 배포 URL 확인, 공개 경계 점검, 복구 절차는 [Vercel 배포 준비](docs/DEPLOYMENT.md)에 정리했습니다.
